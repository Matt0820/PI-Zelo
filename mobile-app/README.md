# App mobile Zelo

**Objetivo:** apontar para o guia do app Expo/React Native e da configuração da API.

O app em `mobile-app/` usa a API FastAPI compartilhada. Consulte [Como rodar](../docs/COMO-RODAR.md), [Arquitetura](../docs/ARQUITETURA.md), [Acessibilidade](../docs/ACESSIBILIDADE.md) e [Chatbot](../docs/CHATBOT.md). O exemplo `mobile-app/.env.example` não contém segredo; `EXPO_PUBLIC_API_URL` é incluída no bundle e não deve receber credenciais.
