# Backend Zelo

**Objetivo:** apontar para o guia técnico canônico da API FastAPI.

Veja [Como rodar](../docs/COMO-RODAR.md) para preparar banco, ambiente e comandos; [Backend](../docs/BACKEND.md) para autenticação, permissões, modelos, endpoints e regras ESAS/triagem; e [Arquitetura](../docs/ARQUITETURA.md) para o fluxo entre clientes, API e persistência.

A API está em `app/`. As dependências de runtime estão em `requirements.txt`; ferramentas de teste estão em `requirements-dev.txt`. O arquivo `.env.example` contém valores de desenvolvimento fictícios e não inclui segredo de produção.
